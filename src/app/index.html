About SignalScope

Real vs AI-Generated Image Detection

SignalScope estimates how likely an image is to be AI-generated, shows the signals behind that estimate, and checks the file's provenance metadata. It covers scenes, objects, art and product images.

Every result is a likelihood assessment, never proof or an accusation. The tool does not identify or make claims about real people.

Operating point & calibration

  • Default threshold 0.5: accuracy 97.80%, FPR 2.35%.
  • Low-miss alternative 0.165 (chosen on validation for ~5% FPR): recall 99.19%, FPR 5.71%.
  • Dual-stream confidence calibrated with temperature scaling on validation (T = 1.066).
  • Scores are shown as likelihoods; wrongly flagging a real photo is treated as the costly error.

Stacking meta-learner

  • L2 (ridge) logistic regression over each member's logit(P(AI)); C = 31.6 chosen by 5-fold CV.
  • Out-of-fold on validation: ROC-AUC 0.9977, accuracy 97.80%.
  • Learned weights: dual-stream +7.53, ViT −0.29, Swin +0.17.
  • It lifts accuracy from 63.8% (majority vote) to 97.8% by down-weighting members that do not transfer to CIFAKE.

Training setup (dual-stream member)

  • Backbone: ResNet34 (ImageNet-pretrained) + 2D-FFT frequency branch
  • Native 32×32 input, no upsampling
  • 6 epochs, batch 256, AdamW (lr 3e-4, wd 0.01), cosine schedule, mixed precision
  • Augmentation: random JPEG re-compression (Q50–95), reflect-pad crop, flip, colour jitter
  • Best epoch selected on validation ROC-AUC
  • Trained on a Kaggle GPU in about 20 minutes

Unseen-generator performance

CIFAKE contains a single generator (Stable Diffusion v1.4), so it has no unseen-generator split and we cannot measure that AUC ourselves. The organizers compute overall and unseen-generator AUC on their held-out set through our predict interface.

Known limitations

  • Trained on one generator: accuracy on newer or unseen generators is not measured and may be substantially lower.
  • The dual-stream member sees images at 32×32, so fine high-resolution artifacts in large images are discarded.
  • ViT and Swin are near chance on CIFAKE (AUC 0.41 and 0.65), so the CIFAKE-fitted stacker relies almost entirely on the dual-stream model.
  • The saliency overlay shows which pixels the dual-stream model's score is most sensitive to; it is not a verified localisation of artifacts.
  • Metadata signatures can be stripped or forged; a declared generator is reported as metadata evidence only.

Methodology

Modules in this submission

Core: real vs AI classifier A: Explanation C: Robustness D: Provenance & metadata F: Deployable web app

Not included in this submission: B (generator attribution), E (image-text consistency), G (active defence).

Pipeline

Image → Level 1: provenance metadata check (explicit AI-generator signature or C2PA manifest) → Level 2: stacked pixel ensemble → calibrated likelihood → explanation cues, saliency overlay and degradation re-test → verdict shown as "likely AI-generated" or "likely real".

Core: stacked 3-model ensemble

Members: ViT-Base (dima806/deepfake_vs_real_image_detection), Swin (Organika/sdxl-detector), and our ResNet34 + 2D-FFT dual-stream model trained on CIFAKE at native 32×32. Each member's P(AI) is fused by a ridge logistic stacking meta-learner fitted on CIFAKE validation images.

Module A: Explanation

Overlays a SmoothGrad saliency map from the dual-stream model (the member that drives the decision), computed at its 32×32 input and placed back on the image. A deletion check tests whether masking the top 10% most salient pixels moves the score more than masking random pixels. Cues list measured signals: each member's P(AI), its share of the stacked log-odds, the image's high-frequency spectral energy, and any metadata signature. Saliency shows sensitivity, not a verified localisation of artifacts.

Module C: Robustness to degradation

Re-encodes the uploaded image at JPEG quality 90/70/50/30 and downscales it to 75/50/25%, re-scores the original and every variant with the same pixel ensemble, and reports whether the verdict holds at each step.

Module D: Provenance & metadata

Reads EXIF, XMP and PNG text fields, and C2PA Content Credentials when present. An explicit AI-generator signature is reported as metadata evidence and decides the verdict at Level 1; otherwise the pixel ensemble decides.

Module F: Deployable web app

FastAPI backend (single-image and batch endpoints) with this bilingual dashboard: drag-and-drop upload, folder scan, adjustable overlay, text-size and high-contrast controls.
