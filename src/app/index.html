Technical Methodology & Forensic Framework Specifications

SIH 2026 C-433 Technical Spec

1. Mandatory Core Task: Unseen Generator Generalisation

SignalScope uses a transfer-learning convolutional backbone paired with spatial noise residual extraction (FFT/DCT high-frequency artifact analysis). Models are trained on the CIFAKE train split and evaluated on its held-out test split (CIFAR-10 photos vs. Stable Diffusion v1.4 images) under calibrated ROC-AUC metrics.

2. Bonus Module A: Faithful Visual Explanations (Grad-CAM)

Provides localized visual saliency heatmaps highlighting exact pixel-level anomalies such as texture warping, irregular specular reflections, and anatomical flaws. Cites grounded natural language points without over-claiming certainty.

3. Bonus Module B: Generator Family & Model Architecture Attribution

Classifies generator families into Latent Diffusion, Generative Adversarial Networks (GANs), and Autoregressive Transformer architectures. Provides granular probability distributions across specific underlying models.

4. Bonus Module C: Robustness Under Image Degradation Vectors

Evaluates prediction resilience under severe lossy compression (JPEG Q30–Q90), downsampling, spatial noise addition, and social media platform re-encoding pipelines.

5. Bonus Module D: Provenance, EXIF & Cryptographic C2PA Verification

Extracts hardware camera EXIF records and validates Coalition for Content Provenance and Authenticity (C2PA) digital signatures to detect synthetic header tampering.

6. Bonus Module E: Multimodal Image-Text Alignment & Claim Verification

Employs CLIP cross-modal semantic embeddings to evaluate alignment between submitted image content and accompanying news captions, identifying out-of-context misrepresentation.

7. Bonus Module F: Real-time Web Dashboard & REST API Architecture

Full-stack web application built following GIGW 3.0 government accessibility standards, backed by FastAPI asynchronous microservices for low-latency batch image scanning.

8. Bonus Module G: Active Defense & Adversarial Attack Vulnerability Testing

Tests classifier robustness against adversarial perturbation attacks (FGSM, PGD, spatial blurring) and applies targeted defensive smoothing to maintain detection reliability.
